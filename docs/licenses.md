# License Policy

Lune source code is licensed as `MIT OR Apache-2.0`.

- MIT terms live in [`../LICENSE-MIT`](../LICENSE-MIT).
- Apache-2.0 terms live in [`../LICENSE-APACHE`](../LICENSE-APACHE).
- Cargo package metadata declares the same expression at the workspace root.

Committed assets are tracked separately in
[`../assets/LICENSES.md`](../assets/LICENSES.md). Each asset entry should list
the path, copyright holder or author, license, source URL or origin, and any
usage notes.
